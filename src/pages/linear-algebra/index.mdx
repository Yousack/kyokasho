# 行列は、基本ベクトルの行き先である

平面上のベクトルは、基本ベクトル **e₁** と **e₂** を何倍かして足し合わせたものとして書けます。したがって、足し算とスカラー倍を保つ写像なら、e₁ と e₂ の行き先さえ決めれば、すべてのベクトルの行き先が決まります。

<LinearMapLab />

たとえば **e₁** が $(a,c)$ へ、**e₂** が $(b,d)$ へ移るなら、その情報を列として並べたものが行列です。

$$
A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}
$$

ここで行列は、数字の長方形として突然現れるのではありません。「二本の基本ベクトルをどこへ送るか」という操作の記録として現れます。次に、この操作が任意のベクトルへどう広がるかを調べます。
